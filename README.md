# QubiCost Electrical

Aplicación independiente de presupuestos eléctricos.

## Ejecutar

Abra `app\QubiCostElectrical.exe`.

## Proyectos

Los presupuestos se guardan como archivos `.qce` y no se mezclan con QUBI Spatial.
Antes de guardar un proyecto existente, QubiCost crea un respaldo numerado en la carpeta de backups junto al archivo.

## Modelos comerciales

Configure el modelo base en **Proyecto → Comercial**. Para una excepción, seleccione una partida en **Itemizado**, haga clic derecho y elija **Modelo comercial de la partida**.

## Fuente

La solución está en `QubiCostElectrical.Wpf.sln` y la publicación ejecutable en `app`.
