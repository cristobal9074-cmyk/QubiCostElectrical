📝 Notas de implementación

✅ Lógica = combo editable (dropdown con = + − × ÷, pero puedes escribir cualquier expresión como ^, %, etc.)

✅ Factor = input numérico independiente. Se deshabilita (opacity 0.4) cuando la lógica es "="

✅ Fórmula = read-only auto-generada: "MAESTRO " + lógica + " " + factor

✅ Cuando Lógica = "=", la fórmula muestra solo MAESTRO (sin factor). Las columnas Lógica, Factor y Fórmula reemplazan a la columna Fórmula anterior.
