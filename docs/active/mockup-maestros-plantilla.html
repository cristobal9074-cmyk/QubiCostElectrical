📐 Cómo funciona: Maestro → Esclavos

Tú defines la cantidad base del Maestro (Bandeja = 10m). Los esclavos calculan automáticamente su cantidad siguiendo al maestro.

Cantidad = 10.00 m

El maestro se calcula con Factor o lo pones manualmente.
Todos los esclavos dependen de esta cantidad base.

💡 Múltiples Maestros: Puedes tener varios maestros en una misma plantilla. Por ejemplo: "Bandeja" (maestro 1) + "Tapa" (maestro 2). Cada esclavo elige a qué maestro sigue mediante el selector "Sigue a Maestro". La fórmula usa el nombre del maestro como variable (ej. BANDEJA / 1.5 o TAPA * 2).
