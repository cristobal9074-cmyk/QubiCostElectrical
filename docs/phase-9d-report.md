# Informe Fase 9D — Recepciones, devoluciones e inventario

## Resumen

Recepción parcial/total, inspección/aceptación, rechazo/daño/faltante/sobrante, devoluciones, lote/ubicación, inventario por proyecto (entradas, salidas, reservas, tránsito, disponible/comprometido), conciliación ordenado/recibido, auditoría y permisos.
