# Guía de usuario — Valor ganado (EVM)

1. Abra un proyecto con cronograma, **baseline** y **fecha de estado** (Seguimiento de avance).
2. Registre avance y costos reales en el workspace de seguimiento.
3. Vaya a **Planificación → Valor ganado (EVM)**.
4. Opcionalmente indique BAC del proyecto y pulse **Calcular**.
5. Revise indicadores, semáforos e interpretación.
6. Cree **Snapshot**, compare versiones y **exporte** (CSV, Excel y PDF).

No modifica baselines ni recalcula el CPM: solo lee datos existentes.
